## Formato de Registro

```
### [BLK-XXX] Título do bloqueador

- **Status**: ACTIVE / RESOLVED / WORKAROUND
- **Fase**: Em qual fase apareceu
- **Sistema**: Qual sistema é afetado
- **Descrição**: O que está acontecendo
- **Causa raiz**: Por que acontece
- **Tentativas**: O que já foi tentado
- **Ciclos**: Quantos ciclos do Gauntlet Loop sem progresso
- **Resolução**: Como foi resolvido (quando aplicável)
```
